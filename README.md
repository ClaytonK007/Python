# Some excercises to learn Python language. 

1. Variables
   *  Declare and print a variable.
   *  Swap two variables without creating a third variable.
   *  Assign multiple variables in one line.
   *  Check the data type of a variable.
   *  Concatenating strings
2. Data Types
   *  Convert string to integer and vice versa along with data type.
   *  Convert float to integer and vice versa along with data type.
   *  Convert boolean to integer and vice versa along with data type.
   *  Convert list to a string and back.
   *  Convert dictionary keys and values to a list.
3. Operators
   *  Arithmetic operators.
   *  Comparison operators.
   *  Logical operators.
   *  Assignment operators.
   *  Bitwise operators.
4. Control flows - if, elif, else statements & loops (for and while)
5. Functions
6. Data Structures
7. String Formatting

More to come...
